# Logos de las herramientas

Descargados el 2026-10-15. SVG originales conservados; la interfaz aplica un filtro CSS blanco sin modificar las formas.

- Keycloak, Meilisearch, Ollama, Qdrant y Umami: https://github.com/simple-icons/simple-icons (distribuidos mediante https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/). Colección CC0; las marcas pertenecen a sus titulares.
- Plausible y Typesense: https://github.com/selfhst/icons/tree/main/svg. SVG de marcas; consultar las condiciones de cada marca para otros usos.
- Lago: https://getlago.com/logo.svg, enlazado por su sitio oficial. Se conserva el wordmark completo.
- PostgreSQL sigue usando los recursos proporcionados en Figma, en ../cards/.
